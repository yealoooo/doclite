### 0.3 使用说明

1. **从头按顺序跑。** 后面的用例要用前面建的数据，每条的"前置"写明了依赖哪条。
2. **每条记一个结果**：通过 / 失败 / 跳过。
   - 失败要写现象：哪一步、看到了什么、和预期差在哪。
   - 跳过要写原因。
3. **失败时留证据**：截图（⌘⇧4 选区域），或者把提示框里的报错原文复制下来。截图文件名用用例编号，例如 `FILE-07.png`。
4. **一步失败，后面能做就接着做**，在备注里写清楚。
   - 前面的用例失败、导致这一条做不了的，记"跳过"，备注写"因 XXX-nn 失败"。
5. **只通过客户端界面操作。**
   - 不要改数据库，不要改配置文件（`server/.env`、客户端数据目录里的文件），不要重启服务端。
   - 标了"需总控配合"的用例，没人配合就记跳过。
   - 终端只用来做这几件事，命令都写在用例里：
     - 准备样本（0.7）；
     - 启动客户端，查有几个客户端进程（`pgrep`）；
     - 往热文件夹里复制文件；
     - 查看下载下来的 zip，查看剪贴板（`pbpaste`）。
6. **预期里的写法**：
   - "提示 `xxx`"指窗口里弹出的提示条，几秒后自动消失。
   - "含 `xxx`"指只要包含这几个字就算对。
   - `<…>` 是会变的部分（数字、时间、名字）。
7. **结尾的结果表**照编号填。

### 0.5 慢的操作（不是卡死）

数据库在远程，下面这些操作要等 1–2 秒，有的更久：

| 操作 | 大概要等 |
|---|---|
| 登录；换账号后第一次打开一个页面；切换项目 | 1–2 秒 |
| 按文件夹分配、批量通过、批量锁定、改编码（要重算档号） | 1–2 秒 |
| 归档（预览、确认）、解除封存、重新归档（对比、确认） | 1–2 秒 |
| 导出：预检、建任务 | 1–2 秒 |
| 导出：生成 | 小任务几秒 |
| 导出列表上的 `交付后变更` 数字 | 最迟约 20 秒才更新 |
| 审计日志：筛选、`加载更多` | 1–2 秒 |
| 存储 `测试连接` | 最长约 30 秒 |
| 客户端第一次打开一张大图（要切块） | 几秒，画面上有 `客户端正在准备原图（第一次打开大图要等几秒）` |
| 每个上传文件依次经过 `等待写入完成` / `排队` / `上传中` | 几秒；热文件夹要等文件 2 秒不变才开始传 |
| 实时刷新：别处的变化出现在当前页面 | 3 秒内；热文件夹上传后约 10 秒内 |

判断规则：
- 转圈、`…中`、`加载中…` 超过 30 秒没有变化，才算卡住。
- 卡住时先截图，再点页面上的 `重试`。没有 `重试` 的，切到别的菜单再切回来。

### 0.7 准备样本（只做一次）

**为什么要现做**：同样内容的图片在一个项目里只入库一次，仓库里的样本以前上传过，直接传会被判成"内容重复"。下面的脚本给每张图加一段这次独有的注释，图片看起来不变，内容就各不相同。

在终端里运行：

```sh
REPO=/Users/yanlong/project/doclite-project/doclite OUT=~/doclite-acceptance python3 - <<'PY'
import os, struct, sys, time, zlib
repo, out = os.environ['REPO'], os.path.expanduser(os.environ['OUT'])
if os.path.exists(out):
    sys.exit(out + ' 已存在：先把它改名或删掉，再运行')
src = os.path.join(repo, 'server/testdata/samples')
run, seq = 'doclite-acceptance %d' % time.time_ns(), [0]

def unique(b):  # 加一段注释：图片不变，内容和以前上传过的都不同
    seq[0] += 1
    t = ('%s #%d' % (run, seq[0])).encode()
    if b[:2] == b'\xff\xd8':  # JPEG：在 APPn 段后插 COM 段
        i = 2
        while b[i] == 0xff and 0xe0 <= b[i + 1] <= 0xef:
            i += 2 + struct.unpack('>H', b[i + 2:i + 4])[0]
        return b[:i] + b'\xff\xfe' + struct.pack('>H', len(t) + 2) + t + b[i:]
    if b[:4] == b'\x89PNG':  # PNG：在 IEND 前插 tEXt 块
        d = b'tEXtComment\x00' + t
        return b[:-12] + struct.pack('>I', len(d) - 4) + d + struct.pack('>I', zlib.crc32(d)) + b[-12:]
    return b + t  # TIFF：末尾追加

def put(rel, sample=None, data=None, raw=False):
    p = os.path.join(out, rel)
    os.makedirs(os.path.dirname(p), exist_ok=True)
    if data is None:
        data = open(os.path.join(src, sample), 'rb').read()
        data = data if raw else unique(data)
    open(p, 'wb').write(data)
    return data
```

## 1. 登录和会话（LOGIN）

### LOGIN-01 首次连接服务器
- 端：客户端｜账号：无｜会保存服务器地址
- 前置：客户端还没配置过服务器地址。打开后直接出现登录页的，记"跳过"，备注"已配置过"。
- 步骤：

  - 页面底部有 `客户端版本 0.2.0`。
